🔄 ¿Cómo actualizar el dashboard?

El dashboard lee los datos directamente del Excel. Para actualizarlo:

1. Guarda y cierra el archivo Excel
2. Ve a la carpeta CONTROL PISO en el escritorio
3. Doble clic en ACTUALIZAR DASHBOARD.bat
4. Presiona F5 aquí para ver los cambios

La tarea automática actualiza el dashboard cada hora.
